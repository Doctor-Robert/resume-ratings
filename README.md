# Оценка резюме

Сервис сравнивает резюме с вакансией с помощью LLM и показывает процент соответствия, сильные стороны и чего не хватает. Войти можно только по логину и паролю, регистрации нет. Все оценки сохраняются.

## Как это устроено

| Часть | Зачем |
|---|---|
| React + Vite + TypeScript | Страницы сайта в браузере |
| shadcn/ui + Tailwind | Готовые кнопки, поля и карточки в фирменных цветах |
| TanStack Router | Переходы между страницами, закрытие страниц без входа |
| TanStack Query | Запросы к серверу, состояния «загрузка» и «ошибка» |
| FastAPI | Сервер: вход, чтение файлов, запрос к LLM, сохранение |
| Pydantic | Проверка данных, в том числе ответа нейросети |
| PostgreSQL + SQLAlchemy | Хранение пользователей и оценок |
| Alembic | Миграции — создание таблиц в базе |
| OpenRouter | Доступ к LLM (есть бесплатные модели) |
| Docker Compose + nginx | Запуск базы, сервера и сайта одной командой |

Вход: пароль хранится в виде хеша (argon2). После входа сервер выдаёт токен (JWT) в cookie; без него все адреса API, кроме входа, отвечают 401.

## Почему такой стек

- **FastAPI + Pydantic** — простой современный сервер, проверка данных «из коробки».
- **PostgreSQL + SQLAlchemy + Alembic** — надёжная база, удобная работа из Python и версии структуры таблиц.
- **JWT в httpOnly-cookie** — браузер сам отправляет токен, а скрипты на странице не могут его украсть.
- **OpenRouter** — один ключ и несколько бесплатных моделей; в `OPENROUTER_MODEL` можно указать несколько через запятую — если одна перегружена или ответила с иероглифами, берётся следующая.
- **nginx** во фронтенд-контейнере отдаёт сайт и передаёт `/api` серверу, поэтому снаружи нужен один порт.

## Запуск локально

Нужен Docker.

```bash
cp .env.example .env     # заполните SECRET_KEY, пароль базы и OPENROUTER_API_KEY
make up                  # собрать и запустить (таблицы в базе создаются сами)
make create-user login=admin password=your-password
```

Сайт откроется на http://localhost. Остановить: `make down`. Миграции применяются автоматически при старте сервера; вручную: `make migrate`.

## Создание пользователя

Открытой регистрации нет. Пользователя создаёт администратор командой:

```bash
make create-user login=имя password=пароль
```

## API

- `POST /api/login`, `POST /api/logout`, `GET /api/me`
- `POST /api/evaluations` — создать оценку (вакансия + файл PDF/DOCX или текст)
- `GET /api/evaluations` — список оценок
- `GET /api/evaluations/{id}` — одна оценка

## Деплой

Сервис развёрнут на VPS: Docker, `git clone`, `.env` с ключами, затем `make up` и `make create-user`.
