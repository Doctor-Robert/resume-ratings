# Оценка резюме

Сервис сравнивает резюме с вакансией с помощью LLM и показывает процент соответствия, сильные стороны и чего не хватает. Войти можно только по логину и паролю, регистрации нет. Все оценки сохраняются.

**Ссылка на сервис:** http://138.124.99.209:8081

## Как это устроено

| Часть | Зачем |
|---|---|
| React + Vite + TypeScript | Страницы сайта в браузере |
| shadcn/ui + Tailwind | Готовые кнопки, поля и карточки в фирменных цветах |
| TanStack Router | Переходы между страницами, закрытие страниц без входа |
| TanStack Query | Запросы к серверу, состояния «загрузка» и «ошибка» |
| FastAPI | Сервер: вход, чтение файлов, запрос к LLM, сохранение |
| Pydantic | Проверка данных, в том числе ответа нейросети |
| PostgreSQL + SQLAlchemy | Хранение пользователей и оценок |
| Alembic | Миграции — создание таблиц в базе |
| OpenRouter | Доступ к LLM (есть бесплатные модели) |
| Docker Compose + nginx | Запуск базы, сервера и сайта одной командой |

Пароль хранится в виде хеша. После входа браузер получает cookie, которая подтверждает, что пользователь вошёл. Страницы оценок и запросы к ним без входа недоступны. Вход, выход и проверка работы сервера доступны без авторизации.

## Почему такой стек

- **FastAPI + Pydantic** — простой современный сервер, проверка данных «из коробки».
- **PostgreSQL + SQLAlchemy + Alembic** — надёжная база, удобная работа из Python и версии структуры таблиц.
- **Cookie для входа** — браузер сам отправляет её серверу, а скрипты страницы не могут прочитать её напрямую.
- **OpenRouter** — один ключ и несколько бесплатных моделей; в `OPENROUTER_MODEL` можно указать несколько через запятую — если одна перегружена или ответила с иероглифами, берётся следующая.
- **nginx** во фронтенд-контейнере отдаёт сайт и передаёт `/api` серверу, поэтому снаружи нужен один порт.

## Запуск локально

Нужен Docker. Создайте `.env` и задайте свои секреты:

```bash
cp .env.example .env
openssl rand -hex 32     # результат задайте для SECRET_KEY
openssl rand -hex 24     # результат задайте для POSTGRES_PASSWORD
# задайте OPENROUTER_API_KEY в .env
make up                  # собрать и запустить (таблицы в базе создаются сами)
make create-user login=admin password=your-password
```

Файл `.env` содержит секреты. Он исключён из Git — не публикуйте и не пересылайте его. При HTTPS задайте `COOKIE_SECURE=true`; при локальном HTTP оставьте `false`. Если изменить `SECRET_KEY`, всем пользователям нужно будет войти снова. Пароль PostgreSQL задаётся при первом создании базы: если поменять его только в `.env` позже, пароль уже созданной базы не изменится.

Порт сайта задаётся в `.env` переменной `WEB_PORT`. При значении `80` сайт откроется на http://localhost, при `8081` — на http://localhost:8081. Остановить проект: `make down`. Таблицы создаются при старте; вручную применить миграции можно командой `make migrate`.

## Создание пользователя

Открытой регистрации нет. Пользователя создаёт администратор командой:

```bash
make create-user login=имя password=пароль
```

Удалить пользователя (вместе с его оценками):

```bash
make delete-user login=имя
```

## API

- `POST /api/login`, `POST /api/logout`, `GET /api/me`
- `POST /api/evaluations` — создать оценку (название и описание вакансии + файл PDF/DOCX или текст резюме)
- `GET /api/evaluations` — список оценок
- `GET /api/evaluations/{id}` — одна оценка

## Деплой

Сервис развёрнут на VPS Ubuntu по адресу http://138.124.99.209:8081. Сейчас он доступен по HTTP. Для HTTPS понадобится домен и настройка TLS; до этого не используйте здесь пароли, которые применяются на других сайтах.
